# Richer Editor

Plugins, tools and rendering helpers that add embeds, emoji, source editing, syntax-highlighted code blocks and more to Filament's Rich Editor.

| Filament version | Package version |
|------------------|-----------------|
| 4.x              | 1.x             |
| 4.x & 5.x        | 2.x             |

## Installation

```bash
composer require awcodes/richer-editor
```

The package's CSS and views need to be added to your Tailwind theme. See [Installation](https://docs.aw.codes/richer-editor/2.x/installation) for that step.
